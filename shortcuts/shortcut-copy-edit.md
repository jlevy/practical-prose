# Copy-Edit Shortcut

## Instructions

Apply the standard documentation guidelines to a document:

1. Read `common-doc-guidelines.md` fully.

2. Audit the target against every rule.
   Be thorough; small issues count.
   - **If you find more than 5 issues:** File a tbd epic bead with a child bead per
     issue. Do this as you proceed.
   - **If 5 or less:** Use your to-do tools to track them.

3. Apply all fixes. Close beads as you fix them.

4. Verify:
   - Check git diff and re-scan for regressions.
   - If beads were used, confirm all child beads and the epic are closed.

5. Report issues found, changes made, and any bead IDs.
