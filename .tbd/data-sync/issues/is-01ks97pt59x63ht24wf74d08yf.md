tools/prose-eval/src/prose_eval/eval_render.py has hardcoded `'18 dims'` strings at lines 178 and 212 in the rendered output.

## Changes

Replace hardcoded `18` with `rs.dimension_count()` so the output adapts automatically as dimensions are added:

- Line 178: `f'**Overall mean (18 dims):** {overall:.2f}  '` → `f'**Overall mean ({rs.dimension_count()} dims):** {overall:.2f}  '`
- Line 212: same pattern in table row construction.

This is a small but valuable change — it removes one source of dim-count drift for every future rubric update.
